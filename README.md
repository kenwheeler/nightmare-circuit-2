# Nightmare Circuit 2

**A free horror-scoring instrument by Ken Wheeler.**

111 factory sounds: eerie synths, basses, bells, pianos, recorded strings, layered voices, pads and effects. Includes sequencing, effects and custom patch Save As / Load.

## [Download the Mac beta →](https://github.com/kenwheeler/nightmare-circuit-2/releases/download/v0.1.0-beta.1/Nightmare-Circuit-2-Apple-Silicon-beta1.zip)

**Apple Silicon Mac · AUv2 + VST3 · about 420 MB**

> **Early beta: not notarized.** macOS may block this download from loading in your DAW. A clean downloaded-recipient installation has not been verified. Do not disable macOS security. If blocked, wait for the signed/notarized release.

### Install

Save your work and close your DAW. Unzip the download. In Finder, use **Go → Go to Folder** and copy the format you need:

- `Nightmare Circuit 2.component` → `~/Library/Audio/Plug-Ins/Components`
- `Nightmare Circuit 2.vst3` → `~/Library/Audio/Plug-Ins/VST3`

Create the folder if needed, then reopen/rescan your DAW. Keep previous plugin bundles as backups; do not delete user presets. Full instructions and third-party credits are inside the ZIP.

### Make it yours

Use **SAVE AS** and **LOAD** above the factory categories to save and share `.trucepreset` sound files. The files contain settings, not copies of the sample library.

### Beta notes

- Apple Silicon only; no Intel or Windows build.
- Installed AUval and AU/VST3 pluginval strictness 5 checks pass on the development Mac. The exact AU passes 333 native render cases.
- DAW/macOS coverage is limited. Native file-picker visual behavior remains unverified; save/load logic has programmatic tests.
- No recordings are claimed to be a same-room choir: the vocal layers combine separate solo performances.
